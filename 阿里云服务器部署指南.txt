# 星愿系统阿里云服务器部署指南

本指南将详细介绍如何将星愿系统部署到阿里云服务器上，让互联网用户可以访问你的应用。

## 一、购买阿里云服务器

1. **注册/登录阿里云账号**
   - 访问阿里云官网：https://www.aliyun.com/
   - 注册或登录你的阿里云账号

2. **购买ECS云服务器**
   - 进入阿里云控制台，点击"云服务器ECS"
   - 点击"创建实例"
   - 选择配置：
     - 地域：选择离你的目标用户最近的地域
     - 实例规格：根据实际需求选择，推荐至少2核4G内存
     - 镜像：推荐选择Ubuntu 20.04或CentOS 7/8
     - 存储：至少40GB云盘
     - 网络：选择默认VPC网络，分配公网IP
     - 安全组：创建或选择一个安全组，确保开放80、443和22端口
   - 设置登录密码或创建SSH密钥对
   - 完成购买

## 二、连接阿里云服务器

### 1. 使用SSH连接（推荐）

**Windows用户**：
- 使用PuTTY、Xshell等SSH客户端
- 输入服务器的公网IP地址、端口（默认为22）
- 输入用户名（通常为root或ubuntu）和密码/密钥文件

**Mac/Linux用户**：
- 打开终端
- 输入命令：`ssh 用户名@公网IP地址`
- 输入密码或使用密钥文件：`ssh -i /path/to/your/key.pem 用户名@公网IP地址`

### 2. 使用阿里云控制台的远程连接

- 登录阿里云控制台，进入ECS实例列表
- 找到你的服务器，点击"远程连接"
- 选择"Workbench远程连接"或"VNC远程连接"
- 按照提示完成连接

## 三、环境配置

### 1. 更新系统

```bash
# Ubuntu系统
sudo apt update && sudo apt upgrade -y

# CentOS系统
sudo yum update -y
```

### 2. 安装Python和pip

```bash
# Ubuntu系统
sudo apt install python3 python3-pip python3-venv -y

# CentOS系统
sudo yum install python3 python3-pip -y
```

### 3. 安装Git

```bash
# Ubuntu系统
sudo apt install git -y

# CentOS系统
sudo yum install git -y
```

### 4. 安装和配置Nginx

```bash
# Ubuntu系统
sudo apt install nginx -y

# CentOS系统
sudo yum install nginx -y

# 启动Nginx并设置开机自启
sudo systemctl start nginx
sudo systemctl enable nginx
```

## 四、部署应用程序

### 1. 克隆项目代码

```bash
# 进入home目录
cd ~

# 克隆项目代码（假设你有一个git仓库）
git clone https://your-git-repo-url.git

# 如果没有git仓库，可以使用scp或其他方式上传代码
# 例如：scp -r /path/to/your/project 用户名@公网IP地址:~/project
```

### 2. 创建虚拟环境并安装依赖

```bash
# 进入项目目录
cd ~/project

# 创建虚拟环境
python3 -m venv venv

# 激活虚拟环境
# Ubuntu/CentOS
source venv/bin/activate

# 安装项目依赖
pip install --upgrade pip
pip install flask flask-sqlalchemy gunicorn
```

### 3. 配置Gunicorn

```bash
# 测试Gunicorn是否能正常运行应用
gunicorn -w 4 -b 0.0.0.0:8000 app:app

# 如果运行成功，可以通过 http://公网IP:8000 访问应用
# 按Ctrl+C停止Gunicorn
```

### 4. 创建systemd服务

```bash
# 创建服务文件
sudo nano /etc/systemd/system/xingyuan.service
```

在文件中添加以下内容（根据实际情况修改路径）：

```ini
[Unit]
Description=Gunicorn instance to serve xingyuan
After=network.target

[Service]
User=root
Group=www-data
WorkingDirectory=/root/project
Environment="PATH=/root/project/venv/bin"
ExecStart=/root/project/venv/bin/gunicorn --workers 3 --bind unix:xingyuan.sock -m 007 app:app

[Install]
WantedBy=multi-user.target
```

保存文件后，启动并启用服务：

```bash
sudo systemctl start xingyuan
sudo systemctl enable xingyuan
sudo systemctl status xingyuan  # 检查服务状态
```

## 五、配置Nginx反向代理

```bash
# 创建Nginx配置文件
sudo nano /etc/nginx/sites-available/xingyuan
```

在文件中添加以下内容（根据实际情况修改路径和域名）：

```nginx
server {
    listen 80;
    server_name www.xingyuan.com xingyuan.com;

    location / {
        include proxy_params;
        proxy_pass http://unix:/root/project/xingyuan.sock;
    }

    location /static {
        alias /root/project/static;
        expires 30d;
    }
}
```

保存文件后，创建符号链接并重启Nginx：

```bash
sudo ln -s /etc/nginx/sites-available/xingyuan /etc/nginx/sites-enabled/
sudo nginx -t  # 检查配置是否正确
sudo systemctl restart nginx
```

## 六、配置域名解析

1. **在阿里云购买域名**（如果还没有）
   - 进入阿里云控制台，点击"域名"
   - 搜索并购买你想要的域名

2. **配置域名解析**
   - 进入"域名解析"控制台
   - 找到你的域名，点击"解析设置"
   - 添加两条A记录：
     - 主机记录：@，记录值：你的服务器公网IP
     - 主机记录：www，记录值：你的服务器公网IP
   - 保存配置

## 七、配置HTTPS（可选但推荐）

使用Let's Encrypt免费SSL证书：

```bash
# 安装Certbot
sudo apt install certbot python3-certbot-nginx -y  # Ubuntu
# 或
sudo yum install certbot python3-certbot-nginx -y  # CentOS

# 运行Certbot获取证书
sudo certbot --nginx -d www.xingyuan.com -d xingyuan.com

# 按照提示完成配置
```

配置自动续期：

```bash
sudo certbot renew --dry-run  # 测试自动续期
```

## 八、数据迁移（如果需要）

如果本地已有数据，可以通过以下方式迁移到服务器：

```bash
# 本地导出数据库
# 假设使用SQLite
sqlite3 players.db .dump > backup.sql

# 上传到服务器
scp backup.sql 用户名@公网IP地址:~/project/

# 在服务器上导入数据库
cd ~/project
rm players.db  # 备份原数据库（如果有）
sqlite3 players.db < backup.sql
```

## 九、安全设置

1. **配置防火墙**

```bash
# Ubuntu系统（使用ufw）
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable

# CentOS系统（使用firewalld）
sudo firewall-cmd --permanent --add-service=ssh
sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --permanent --add-service=https
sudo firewall-cmd --reload
```

2. **修改SSH端口（可选但推荐）**

```bash
sudo nano /etc/ssh/sshd_config
# 将Port 22改为其他端口（如Port 2222）
sudo systemctl restart sshd
sudo ufw allow 2222/tcp  # 或使用firewalld
```
